# .jal/memory

Project-specific memory for crew: deviations from the template,
accepted `bun audit` findings with a written reason, and anything a future
scaffold run or reviewer should know that is not obvious from the code.

Add one dated entry per event, most recent first. Example:

```
## 2026-08-06 - deviation: added @mengai/analytics package

Reason: ...
Approved by: Brian
```

Nothing to record yet for a freshly scaffolded project.
